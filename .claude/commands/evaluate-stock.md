# Stock Evaluation Skill

对指定A股股票进行全面评估，输出结构化报告。

## 输入参数

$ARGUMENTS

## 执行流程

### 第1步：基本面分析

用 MCP `web_search` 搜索以下维度，每个维度 max_results=8：

1. **财报数据**：搜索 `{股票名} {代码} 年报 一季报 营收 净利润`
2. **业务战略**：搜索 `{股票名} AI 战略 新产品 业务布局 {当前年份}`
3. **风险负面**：搜索 `{股票名} {代码} 风险 亏损 ST 审计 减持 强调事项`
4. **机构评级**：搜索 `{股票名} {代码} 研报 评级 目标价 {当前年份}`
5. **同行对比**：搜索 `{同行公司列表} {当前年份} 营收 净利润 对比`

抓取关键文章全文：用 MCP `web_fetch_page` 获取 3-5 篇核心文章内容，keywords 设为相关关键词列表。

### 第2步：估值与量化分析

用 MCP 量化工具获取精确数据：

1. **实时行情与估值指标**：调用 `mcp_stock_quote(code)` 获取
   - 当前价格、涨跌幅、成交量、换手率
   - PE（动态/静态）、PB、PS
   - 市值、总股本、流通股本
   - 营收YoY、利润YoY
   - 所属行业

2. **财务报表分析**：调用 `mcp_stock_financial(code, report_type, count=4)` 获取
   - `report_type="income"` → 近4期利润表（营收、净利润、扣非净利润、三费、营业利润率、增速）
   - `report_type="balance"` → 近2期资产负债表（总资产、总负债、资产负债率、货币资金、应收账款）
   - `report_type="cashflow"` → 近2期现金流量表（经营/投资/筹资现金流）
   - 重点关注：营收增速趋势、净利润增速趋势、三费占比变化、经营现金流与净利润匹配度、资产负债率趋势

3. **K线走势分析**：调用 `mcp_stock_kline(code, days=120)` 获取
   - 近120日OHLCV数据
   - 日涨跌幅序列
   - 计算趋势（均线支撑/压力）
   - 识别涨停/跌停日、放量日

4. **估值历史百分位**：调用 `mcp_stock_valuation_history(code)` 获取
   - 当前PE/PB在250日价格区间中的位置
   - 52周最高/最低价
   - MA5/MA20偏离度
   - 价格百分位

5. **资金流向分析**：调用 `mcp_stock_fund_flow(code, days=30)` 获取
   - 主力净流入趋势（近30日）
   - 超大单/大单/中单/小单净流入分布
   - 判断主力做多/做空意图

6. **股东结构分析**：调用 `mcp_stock_shareholders(code, top_n=10)` 获取
   - 前十大股东持股比例及变动
   - 前十大流通股东持股比例及变动
   - 关注：机构持股集中度变化、大股东增减持动向、股东类型分布

7. **因子评分**：调用 `mcp_factor_composite(code)` 获取
   - 8因子（价值/成长/质量/股息/动量/资金流/波动/流动性）综合评分
   - 各因子覆盖率及缺失说明
   - 综合信号（buy/hold/watch/sell）

8. **分红数据**：调用 `mcp_stock_dividend(code)` 获取
   - 近年每股分红(DPS)、股息率、分红方案进度
   - 分红连续性（连续分红年数）

### 第2.5步：产业链与行业分析

用 MCP 结构化工具获取产业链和行业数据：

1. **产业链定位**：调用 `mcp_industry_chain(code)` 获取
   - 上游行业：原材料/零部件供应商
   - 下游行业：终端应用/客户
   - 互补行业：配套产品/服务
   - 替代行业：替代产品/竞争威胁
   - 同行业竞争对手列表（按市值排名）
   - 行业集中度（Top3占比）和公司在行业中的排名

2. **行业基准**：调用 `mcp_industry_benchmarks(industry)` 获取
   - 行业PE/PB/股息率中位数
   - 行业营收/利润增速中位数

3. **宏观环境**：调用 `mcp_macro_indicators()` 获取
   - PMI（制造业+非制造业）
   - CPI月率
   - GDP季度增速（一二三产业拆分）
   - LPR利率（1Y+5Y）
   - M2同比增速
   - 结合行业属性判断宏观对该行业的利好/利空

### 第2.6步：分析师观点与盈利预测

用 MCP 结构化工具获取专业分析师数据：

1. **研报评级与盈利预测**：调用 `mcp_stock_analyst(code)` 获取
   - 研报列表（评级、机构、日期、标题）
   - 买入/增持/中性/减持/卖出的比例 → 机构共识评级
   - EPS盈利预测（2026/2027/2028年）
   - 行业平均EPS对比

2. **机构参与度**：从 mcp_stock_analyst 返回的 institutional_participation 获取
   - 机构参与度百分比
   - 判断机构关注度

### 第3步：公告与事件

调用 `mcp_stock_announcements(code, count=20)` 获取近期公告，重点关注：
- 异常波动公告
- 增持/减持公告
- 重大合同/投资
- 年报/季报披露
- 回购/股权激励

### 第4步：限售解禁与减持压力

调用 `mcp_stock_unlock_schedule(code)` 获取限售股解禁计划：
- 近期是否有大规模解禁（解禁股数占总股本比例）
- 解禁市值及对流通盘的冲击估算
- 解禁类型（首发原股东、定向增发、股权激励等）
- 结合股东持股数据评估减持压力

### 第5步：大盘环境

调用 `mcp_market_index(days=60)` 获取大盘指数走势：
- 上证指数/深证成指近60日走势及涨跌幅
- 大盘处于上升/震荡/下跌通道
- 个股走势与大盘的相关性
- 当前市场情绪偏乐观还是悲观

### 第6步：行业景气度

用 MCP `web_search` 搜索行业趋势：

1. 搜索 `{行业名} 行业景气度 {当前年份} 增速 市场规模`
2. 搜索 `{行业名} 政策 支持 {当前年份}`
3. 搜索 `{行业名} 产业链 龄头 产能 {当前年份}`

结合 `mcp_stock_quote` 返回的行业字段确定行业归属。
结合 `mcp_industry_benchmarks(industry)` 获取行业基准数据（行业PE/PB中位数等）。

### 第8步：存储报告和触发条件

**必须执行**——报告生成后，调用以下两个MCP工具将数据存入CLI数据库：

1. **存储报告**：调用 `save_evaluation_report(code, content, score)`
   - `code`：股票代码
   - `content`：完整markdown报告内容（上述模板生成的全部文本）
   - `score`：综合评分（如 22/50 则 score=22）

2. **存储触发条件**：调用 `save_trigger_conditions(code, name, triggers_json)`
   - `code`：股票代码
   - `name`：股票名称
   - `triggers_json`：JSON数组，每项包含 type、value、description，例如：
     ```json
     [
       {"type": "price_stop_loss", "value": 35.5, "description": "止损价 35.5 元"},
       {"type": "price_stop_profit", "value": 45.0, "description": "止盈价 45 元"},
       {"type": "pe_high", "value": 50, "description": "PE超50预警"},
       {"type": "near_52w_low", "value": 33.0, "description": "接近52周最低价"}
     ]
     ```
   - 触发条件应基于分析结论设定，例如：止损价设为关键支撑位、止盈价设为压力位或估值上限

存储后，用户可以通过 `hermes report <code>` 查看完整报告，`hermes dashboard` 展示触发条件，`hermes portfolio check` 自动巡检触发条件是否命中。

### 工具调用注意事项

- **禁止使用 Claude Code 内置的 WebSearch/WebFetch，必须使用本项目 MCP 工具**
- 网页搜索：用 MCP `web_search`（backend="google"，失败自动切 lite）
- 新闻搜索：用 MCP `web_search_news`（失败会自动 fallback 到 web_search）
- 网页内容：用 MCP `web_fetch_page`（指定 keywords 过滤相关片段）
- 量化数据用 MCP `mcp_stock_quote`、`mcp_stock_kline`、`mcp_stock_fund_flow`、`mcp_stock_announcements`、`mcp_stock_valuation_history`、`mcp_stock_financial`、`mcp_stock_shareholders`、`mcp_stock_unlock_schedule`、`mcp_market_index`、`mcp_stock_dividend`
- 因子评分用 MCP `mcp_factor_composite`、`mcp_factor_score`
- 产业链用 MCP `mcp_industry_chain`
- 行业基准用 MCP `mcp_industry_benchmarks`
- 宏观指标用 MCP `mcp_macro_indicators`
- 研报/分析师用 MCP `mcp_stock_analyst`
- 报告存储用 MCP `save_evaluation_report`、`save_trigger_conditions`
- 所有金额单位统一为"亿元"（mcp_stock_financial 已自动转换）
- 报告末尾注明信息来源和时间
